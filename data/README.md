# data 目录约定

| 子目录 | 内容 | 是否入库 |
| --- | --- | --- |
| `raw/` | 原始采集数据（实车/台架），放入后只读 | 否 |
| `interim/` | 清洗、时间对齐、单位统一等中间产物 | 否 |
| `processed/` | 可直接用于训练/标定的最终数据集 | 否 |
| `external/` | 公开数据集（NASA Ames、CALCE、Oxford 等） | 否 |

约定：

- 原始数据一旦放入 `raw/` 不再改动，任何变换都写成 `scripts/` 中的流水线脚本；
- 每个数据文件配一个同名 `.md` 或在 `docs/` 中记录来源、采样率、工况、温度与老化阶段；
- 大文件如需共享，通过网盘分发，在对应目录留下 `README` 说明获取方式。
