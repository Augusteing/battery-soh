# 数据处理方法（技术报告草稿 · 第 X 节）

## 1. 数据来源

本工作使用麻省理工学院—斯坦福—丰田研究中心公开的 MATR 快充老化数据集
（Severson et al., *Nature Energy* 4, 383–391, 2019），电芯为 A123 磷酸铁锂/石墨 18650 电池。
共使用三个批次：

| 批次 | 电池数 | 说明 |
| --- | --- | --- |
| 2017-05-12 | 46 | 主实验批次，23 种快充协议 |
| 2017-06-30 | 48 | 扩充批次 |
| 2018-04-12 | 46 | 扩充批次 |
| 合计 | 140 | 72 种充放电协议 |

原始数据为 MATLAB v7.3（HDF5）格式，每个批次包含逐循环的放电容量、充电容量、
内阻、温度（最高/平均/最低）、充电时间，以及循环寿命与协议标注。

## 2. SOH 标签定义

为抑制初期容量波动，每只电池的基准容量 Q₀ 取前 10 个正容量循环放电容量的中位数：

    Q₀ = median({Q_discharge(1), ..., Q_discharge(10)})
    SOH(t) = Q_discharge(t) / Q₀

处理流程：

1. 解析 `.mat` 文件，提取逐循环汇总字段；
2. 剔除容量为 0 的化成/初始化循环；
3. 按循环序号排序；
4. 计算 Q₀ 与逐循环 SOH；
5. 附电池 ID（批次_序号）、批次、协议、循环寿命等元数据。

处理后共 **140 只电池、114,692 个循环样本**，单只电池循环数 170–2237，
SOH 最低降至 0.761，覆盖新电池至明显老化阶段。

## 3. 特征工程

每个循环构建 14 维特征，**全部仅依赖当前及历史信息**（滚动窗口、差分均不向未来看），
不使用容量水平值作为特征，避免与 SOH 标签高度重合的平凡特征。

| 类别 | 特征 | 说明 |
| --- | --- | --- |
| 当前观测 | ir, tmax, tavg, tmin, chargetime | 内阻、温度、充电时间 |
| 派生量 | cumulative_charge | 累积充入电量（自电池开始累计） |
| 派生量 | temp_amp | 温度振幅 tmax − tmin |
| 派生量 | chargetime_ratio | 充电时间 / 10 循环滚动均值 |
| 滚动窗口（10） | ir_mean10, ir_std10 | 内阻滚动均值/方差 |
| 滚动窗口（10） | tavg_mean10, tavg_std10 | 平均温度滚动均值/方差 |
| 滚动窗口（10） | ir_deriv10, capacity_deriv10 | 内阻/容量 10 循环差分 |

滚动窗口至少 3 个有效观测；窗口未填满的早期循环以 NaN 处理并在建表时剔除。
最终特征表为 **108,886 个样本、138 只电池**（2 只电池因有效循环数不足被过滤）。

## 4. 数据划分与防泄漏

为保证验证结论可信，设计两套相互独立的数据划分：

1. **按电池随机划分（70/15/15）**：测试集为训练中未出现的新电池（同协议族），
   用于衡量跨电池泛化能力；
2. **按协议隔离划分（70/15/15）**：以充放电协议为单位划分，测试协议在训练中完全不可见，
   用于衡量对"未见工况"的适应能力（对应赛题变工况要求）。

防泄漏措施：

- 滚动特征与差分只使用过去信息；
- 特征标准化统计量仅在训练集上拟合；
- 同一电池（按电池划分）或同一协议（按协议划分）的全部样本绝不跨集合；
- SOH 标签裁剪至 [0.7, 1.2]，仅影响 4 个异常行（早期容量伪高值），不改变其余标签。

## 5. 可复现性

数据构建流水线脚本：

    scripts/build_matr_soh_table.py   # 原始 .mat -> SOH 标签表
    scripts/build_matr_features.py    # SOH 标签表 -> 14 维特征表

产物：`data/processed/matr_soh_table.parquet`、`data/processed/matr_features.parquet`。
